      K:04 Series

      K:04

      K:04 — беспроводная механическая сплит-клавиатура c модульной хотсвап-системой, 58 настраиваемыми клавишами и поддержкой трекбола, тачпада или энкодера на любой половинке

      K:04 Mini

      K:04 Mini — компактная версия беспроводной механической сплит-клавиатуры K:04 c 46 настраиваемыми клавишами и поддержкой трекбола, тачпада или энкодера на любой половинке

      Обзор

      1. разъем USB-C
      2. hot-swap сокет подключения модулей
      3. кнопка: однократное нажатие — reset, двукратное нажатие (быстро) — bootloader
      4. заглушка на корпус (при использовании клавиатуры без модулей)
      5. переключатель питания клавиатуры
      6. вспомогательное окно для разбора корпуса клавиатуры
      Дополнительный свитчплейт

      Клавиатуры серии K:04 комплектуются двойным свитчплейтом. Это обусловлено высотой поддерживаемых MX свитчей, если Вы хотите использовать низкопрофильные свитчи, то Вам нужно установить только нижний свитчплейт

      Для установки среднепрофильных свитчей - используйте оба свитчплейта

      LED индикация
      • Цвет слоя — показывает на двух половинках цвет активного слоя 0-15, настраивается в Entropy
      • BT profile — при переключении BT0-BT4 кратко показывает на левой половинке цвет выбранного профиля
      • Battery charge level — показывает на каждой половинке её заряд цветом: 0-20% красный, 21-40% оранжевый, 41-74% жёлтый, 75-100% зелёный
      • Low battery — если заряд <=20%, каждая половинка показывает свой заряд коротким красным миганием раз в 2 секунды
      • BLE advertising — левая половинка медленно мигает синим: клавиатура доступна для подключения
      • BLE reconnecting — левая половинка быстро мигает синим: пытается переподключиться
      • BLE pairing — левая половинка дважды мигает голубым цветом: режим спаривания
      • Host connected — левая половинка дважды мигает зелёным: клавиатура подключилась к компьютеру по Bluetooth
      • Split missing — одна из половинок мигает коротким жёлтым: вторая половинка не подключена
      • Split unpaired — одна из половинок мигает коротким оранжевым: нет/сброшена привязка половинок
      • Split connected — обе половинки мигают двойным коротким жёлтым: половинки соединились
      • System off / deep sleep — обе половинки перед уходом в сон кратковремено светится фиолетовым цветом

      Подключение

      • K:04 работает с устройствами под управлением Windows, macOS, Linux, Android, iOS
      • Подключение клавиатуры осуществляется посредством Plug and Play (PnP), дополнительная установка драйверов не требуется
      • Клавиатура поставляется готовой для подключения к вашему устройству с актуальной на момент покупки прошивкой
      Проводное подключение

      Клавиатура поддерживает проводное подключение через разъем USB-C. Используйте комплектный кабель для подключения, либо любой другой кабель с USB-C разъемом и поддержкой передачи данных

      Левая половинка K:04 является главной (master) и предназначена для проводного подключения
      Беспроводное подключение
      1. Включите питание на левой и правой половинках клавиатуры - половинки уже синхронизированы между собой
      2. Выберите профиль подключения на клавиатуре - если нужно подключить на несколько устройств, для первого подключения можете пропустить этот шаг
      3. Подключите клавиатуру к устройству - включите Bluetooth на устройстве, затем выполните сопряжение в настройках устройства
      Подключение дополнительных устройств
      1. Включите Bluetooth на устройстве, к которому подключаете клавиатуру
      2. Включите клавиатуру, переведя переключатели питания половинок на нижних крышках в положение ВКЛ, клавиатура перейдёт в режим сопряжения
      3. Переключите BT‑профиль на клавиатуре при помощи соответствующих кнопок (3 слой в раскладке по умолчанию)
      4. Начните поиск Bluetooth на устройстве и найдите клавиатуру в списке
      5. Подключите клавиатуру к устройству

      Зарядка, мониторинг заряда

      • для зарядки клавиатуры используйте комплектный или любой кабель USB-C
      • для полной зарядки аккумулятора необходимо примерно 1,5-2 часа
      • мониторить уровень заряда половинок можно при помощи LED-индикации (клавиша BT Battery)
      Для зарядки аккумулятора клавиатуры переключатель питания половинки снизу должен быть в положении Вкл

      Модули

      K:04 поддерживает модульную систему для обеих половинок клавиатуры

      • Размер шара: 32 мм
      • Scroll Mode для плавной прокрутки
      • Sniper Mode для точного управления курсором
      • Text Mode для удобной навигации по тексту
      • Рабочая площадь: 43х40 мм
      • Scroll Mode для плавной прокрутки
      • Sniper Mode для точного управления курсором
      • Text Mode для удобной навигации по тексту
      • Жесты (тап/скольжение): один палец (левая кнопка/перемещение), два пальца (правая кнопка/скролл)
      Жесты для тачпада по умолчанию выключены в прошивке, чтобы их включить в Entropy перейдите во вкладку Настройки - Настройки модулей - включите Жесты тачпада
      • Тип датчика: механический
      • Диапазон вращения: 360 градусов
      • Примеры применения: регулировка громкости, яркости, навигация

      Особенности подключения модульной системы

      • после замены одного модуля на другой его необходимо включить в Entropy
      • модули устанавливаются в разъёмы на любой половинке без перепрошивки
      • при замене одного модуля на другой конфигурация сохраняется
      • одинаковые модули можно использовать на обеих половинках
      • если модуль не установлен, разъём закрывается аккуратной заглушкой
      • каждый модуль настраивается отдельно для каждой половинки

      Настройка

      Для переназначения клавиш и настройки клавиатуры используйте графический конфигуратор Entropy

      Настройка модулей

      Для использования модуля энкодера, тачпада или трекбола Вам необходимо его включить в настройках клавиатуры. Откройте конфигуратор Entropy, вверху основного окна конфигуратора перейдите во вкладку Настройки - Настройки модулей, в пункте Сторона модуля выберите нужную половинку и в пункте Модуль выберите подключаемый модуль

      Если Вы не планируете использовать модули, то рекеомендуется отключить их в Entropy для увеличения автономности клавиатуры

      Перепрошивка/обновление встроенного ПО

      Прошивка требуется в случаях, когда:

      • Вышло обновление прошивки на keymap_hub
      • Требуется вернуть клавиатуру к заводским настройкам

      Подготовка к прошивке

      Скачайте актуальные файлы прошивок Reset all settings for RMK и K:04/mini/micro для левой и правой половинок с keymap_hub

      Прошивка для сброса настроек

      Подключите USB-C кабелем устройство с прошивкой (ПК, ноутбук и т.п.) и левую половинку клавиатуры, дважды нажмите кнопку Reset с обратной стороны клавиатуры

      Клавиатура перейдёт в режим загрузчика и откроется папка-хранилище (если на вашем устройстве отключен автозапуск подключаемых дисков, то перейдите в папку-хранилище вручную)

      Скопируйте или перетащите Uf2 файл Reset all settings for RMK, после чего клавиатура должна перезагрузиться

      Reset all settings for RMK прошивка нужна для затирания внутренней памяти клавиатуры. Она сбрасывает настройки профилей подключения и синхронизации половинок
      Повторите те же шаги для правой половинки

      Завершение прошивки

      Снова дважды нажмите кнопку Reset с обратной стороны левой половинки и дождитесь, когда она перейдёт в режим загрузчика (откроется папка-хранилище)

      Скопируйте или перетащите Uf2 файл прошивки K:04/mini/micro для левой половинки, после чего она должна перезагрузиться

      Если при копировани прошивки появляется окно с ошибкой копирования, то просто игнорируйте это сообщение
      Повторите те же шаги для правой половинки, но используйте Uf2 файл прошивки K:04/mini/micro уже для правой половинки

      Прошивка завершена, можно подключать клавиатуру к вашему устройству!

      Уход и обслуживание

      • Периодически очищайте корпус от пыли и загрязнений сухой или влажной тканевой салфеткой
      • Для модуля трекбола: следите за чистотой шара, керамических подшипников и полости установки шара
      Для извлечения шара вытяните его в противоположную сторону относительно фиксатора на корпусе модуля
      Не используйте агрессивные чистящие средства (ацетон, бензин, растворители (646, уайт-спирит), концентрированные кислоты и щелочи)!
      Не допускайте попадания жидкости внутрь устройства!
