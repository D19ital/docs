**K:04** — беспроводная механическая сплит-клавиатура, модульной хотсвап-системой, 58 настраиваемыми клавишами и поддержкой трекбола, тачпада или энкодера на любой половинке

{{< /details >}}

## Обзор

![image](/images/k04_series/k03_view.jpg)

1. разъем USB-C
2. hot-swap сокет подключения модулей
3. кнопка: однократное нажатие — reset, двукратное нажатие (быстро) — bootloader
4. заглушка на корпус (при использовании клавиатуры без модулей)
5. переключатель питания клавиатуры
6. вспомогательное окно для разбора корпуса клавиатуры

{{< details title="LED индикация" closed="true" >}}

- **Цвет слоя** — показывает на двух половинках цвет активного слоя 0-15, настраивается в [Entropy](https://github.com/ergohaven/entropy)
- **BT profile** — при переключении BT0-BT4 кратко показывает на левой половинке цвет выбранного профиля
- **Battery charge level** — показывает на каждой половинке её заряд цветом: 0-20% красный, 21-40% оранжевый, 41-74% жёлтый, 75-100% зелёный
- **Low battery** — если заряд <=20%, каждая половинка показывает свой заряд коротким красным миганием раз в 2 секунды
- **BLE advertising** — левая половинка медленно мигает синим: клавиатура доступна для подключения
- **BLE reconnecting** — левая половинка быстро мигает синим: пытается переподключиться
- **BLE pairing** — левая половинка дважды мигает голубым цветом: режим спаривания
- **Host connected** — левая половинка дважды мигает зелёным: клавиатура подключилась к компьютеру по Bluetooth
- **Split missing** — одна из половинок мигает коротким жёлтым: вторая половинка не подключена
- **Split unpaired** — одна из половинок мигает коротким оранжевым: нет/сброшена привязка половинок
- **Split connected** — обе половинки мигают двойным коротким жёлтым: половинки соединились
- **System off / deep sleep** — обе половинки перед уходом в сон кратковремено светится фиолетовым цветом

{{< /details >}}

## Подключение

- **K:04** работает с устройствами под управлением Windows, macOS, Linux, Android, iOS
- Подключение клавиатуры осуществляется посредством Plug and Play (PnP), дополнительная установка драйверов не требуется
- Клавиатура поставляется готовой для подключения к вашему устройству с актуальной на момент покупки прошивкой

{{% details title="Проводное подключение" closed="true" %}}

Клавиатура поддерживает проводное подключение через разъем USB-C. Используйте комплектный кабель для подключения, либо любой другой кабель с USB-C разъемом и поддержкой передачи данных.
{{< callout type="info" >}}
  **Левая половинка** K:03 – Wireless Edition является **главной (master)** и предназначена для проводного подключения
{{< /callout >}}
{{% /details %}}

{{% details title="Беспроводное подключение" closed="true" %}}
1. **Включите питание на левой и правой половинках клавиатуры** - половинки уже синхронизированы между собой
2. **Выберите профиль подключения на клавиатуре** - если нужно подключить на несколько устройств, для первого подключения можете пропустить этот шаг
3. **Подключите клавиатуру к устройству** - включите Bluetooth на устройстве, затем выполните сопряжение в настройках устройства
{{% /details %}}

{{% details title="Подключение дополнительных устройств" closed="true" %}}

1. Включите Bluetooth на устройстве, к которому подключаете клавиатуру
2. Включите клавиатуру, переведя переключатели питания половинок на нижних крышках в положение *ВКЛ*, клавиатура перейдёт в режим сопряжения
3. Переключите BT‑профиль на клавиатуре при помощи соответствующих кнопок (3 слой в раскладке по умолчанию)
3. Начните поиск Bluetooth на устройстве и найдите клавиатуру в списке
4. Подключите клавиатуру к устройству
{{% /details %}}

### Особенности подключения модульной системы
- после замены одного модуля на другой его необходимо выбрать в [Entropy](https://github.com/ergohaven/entropy) во вкладку **"Настройки" - "Настройки модулей"**
- модули устанавливаются в разъёмы на любой половинке без перепрошивки
- при замене одного модуля на другой конфигурация сохраняется
- одинаковые модули можно использовать на обеих половинках
- если модуль не установлен, разъём закрывается аккуратной заглушкой
- каждый модуль настраивается отдельно для каждой половинки
