[Entropy](/software/entropy/) — графический конфигуратор Ergohaven для переназначения клавиш, работы со слоями и настройки функций совместимых устройств

## Подключение к конфигуратору

1. [Установите Entropy](/software/entropy/installation/)
2. Подключите устройство по USB или Bluetooth
3. Откройте меню **Раскладка** и выберите устройство
4. Дождитесь загрузки раскладки и параметров

{{< callout type="important" >}}
Для первоначальной настройки K:04 и выбора установленных модулей используйте подключение по USB
{{< /callout >}}
