[Entropy](/software/entropy/) is the Ergohaven graphical configurator for remapping keys, working with layers, and configuring supported device features

## Connecting to the configurator

1. [Install Entropy](/software/entropy/installation/)
2. Connect the device via USB or Bluetooth
3. Open the **Layout** menu and select the device
4. Wait for the layout and settings to load

{{< callout type="important" >}}
Use a USB connection for initial K:04 configuration and when selecting installed modules
{{< /callout >}}
