{{< details title="LED индикация" closed="true" >}}

- **Цвет слоя** — показывает на двух половинках цвет активного слоя 0-15, настраивается в [Entropy](https://github.com/ergohaven/entropy)
- **BT profile** — при переключении профилей BT0-BT4 кратко показывает на левой половинке цвет выбранного профиля
- **Battery charge level** — показывает заряд каждой половинки цветом: 0-20% красный, 21-40% оранжевый, 41-74% жёлтый, 75-100% зелёный
- **Low battery** — если заряд 20% или ниже, каждая половинка показывает свой заряд коротким красным миганием раз в 2 секунды
- **BLE advertising** — левая половинка медленно мигает синим: клавиатура доступна для подключения
- **BLE reconnecting** — левая половинка быстро мигает синим: пытается переподключиться
- **BLE pairing** — левая половинка дважды мигает голубым цветом: режим спаривания
- **Host connected** — левая половинка дважды мигает зелёным: клавиатура подключилась к компьютеру по Bluetooth
- **Split missing** — одна из половинок мигает коротким жёлтым: вторая половинка не подключена
- **Split unpaired** — одна из половинок мигает коротким оранжевым: нет или сброшена привязка половинок
- **Split connected** — обе половинки мигают двойным коротким жёлтым: половинки соединились
- **System off / deep sleep** — обе половинки перед уходом в сон кратковременно светятся фиолетовым цветом

{{< /details >}}

## Подключение

- **K:04** работает с устройствами под управлением Windows, macOS, Linux, Android, iOS
- Подключение клавиатуры осуществляется по принципу Plug and Play (PnP), дополнительная установка драйверов не требуется
- Клавиатура поставляется готовой к подключению к вашему устройству с актуальной на момент покупки прошивкой

{{% details title="Проводное подключение" closed="true" %}}

Клавиатура поддерживает проводное подключение через разъём USB-C. Используйте комплектный кабель или любой другой кабель с USB-C и поддержкой передачи данных
{{< callout type="info" >}}
  **Левая половинка** K:04 является **главной (master)** и предназначена для проводного подключения
{{< /callout >}}
{{% /details %}}

{{% details title="Беспроводное подключение" closed="true" %}}
1. **Включите питание на левой и правой половинках клавиатуры** — половинки уже синхронизированы между собой
2. **Выберите профиль подключения на клавиатуре** — если нужно подключить клавиатуру к нескольким устройствам, для первого подключения можете пропустить этот шаг
3. **Подключите клавиатуру к устройству** — включите Bluetooth на устройстве, затем выполните сопряжение в настройках устройства
{{% /details %}}

{{% details title="Подключение дополнительных устройств" closed="true" %}}

1. Включите Bluetooth на устройстве, к которому подключаете клавиатуру
2. Включите клавиатуру, переведя переключатели питания половинок на нижних крышках в положение *ВКЛ*, клавиатура перейдёт в режим сопряжения
3. Переключите BT‑профиль на клавиатуре при помощи соответствующих кнопок (3-й слой в раскладке по умолчанию)
4. Начните поиск Bluetooth на устройстве и найдите клавиатуру в списке
5. Подключите клавиатуру к устройству
{{% /details %}}

## Зарядка, мониторинг заряда

- Для зарядки клавиатуры используйте комплектный или любой другой кабель USB-C
- Для полной зарядки аккумулятора необходимо примерно 1,5-2 часа
- Отслеживать уровень заряда половинок можно при помощи LED-индикации (клавиша **BT Battery**)

{{< callout type="warning" >}}
  Для зарядки аккумулятора клавиатуры переключатель питания половинки снизу должен быть в положении **ВКЛ**
{{< /callout >}}

### Особенности подключения модульной системы
- после замены одного модуля на другой выберите его в [Entropy](https://github.com/ergohaven/entropy)
- модули устанавливаются в разъёмы на любой половинке без перепрошивки
- при замене одного модуля на другой конфигурация сохраняется
- одинаковые модули можно использовать на обеих половинках
- если модуль не установлен, разъём закрывается аккуратной заглушкой
- каждый модуль настраивается отдельно для каждой половинки

## Настройка

Для переназначения клавиш и настройки клавиатуры используйте графический конфигуратор [Entropy](https://github.com/ergohaven/entropy)

{{< details title="Настройка модулей" closed="true" >}}

Для использования модуля энкодера, тачпада или трекбола включите его в настройках клавиатуры. Откройте конфигуратор [Entropy](https://github.com/ergohaven/entropy), вверху основного окна перейдите во вкладку **Настройки** - **Настройки модулей**, в пункте **Сторона модуля** выберите нужную половинку, а в пункте **Модуль** — подключаемый модуль

![K:04 - настройка модулей](/images/k04_series/k04_modules_settings_ru.gif)

{{< callout type="info" >}}
  Если вы не планируете использовать модули, рекомендуется отключить их в [Entropy](https://github.com/ergohaven/entropy) для увеличения автономности клавиатуры
{{< /callout >}}

## Перепрошивка/обновление встроенного ПО

Обновление или перепрошивка требуется в случаях, когда:
- Вышло обновление прошивки на [keymap_hub](https://github.com/ergohaven/keymap_hub)
- Требуется вернуть клавиатуру к заводским настройкам

{{% steps %}}

### Подготовка к прошивке

Скачайте актуальные файлы прошивок *Reset all settings for RMK* и *K:04/mini/micro* для левой и правой половинок с [keymap_hub](https://github.com/ergohaven/keymap_hub)

### Прошивка для сброса настроек

Подключите USB-C кабелем устройство с прошивкой (ПК, ноутбук и т.п.) и левую половинку клавиатуры, дважды нажмите кнопку *Reset* с обратной стороны клавиатуры

{{< callout type="info" >}}
  Клавиатура перейдёт в режим загрузчика и откроется папка-хранилище (если на вашем устройстве отключен автозапуск подключаемых дисков, то перейдите в папку-хранилище вручную)
{{< /callout >}}

Скопируйте или перетащите UF2-файл *Reset all settings for RMK*, после чего клавиатура должна перезагрузиться

{{< callout type="info" >}}
  Прошивка Reset all settings for RMK нужна для затирания внутренней памяти клавиатуры. Она сбрасывает настройки профилей подключения и синхронизации половинок
{{< /callout >}}

{{< callout type="important" >}}
  Повторите те же шаги для правой половинки
{{< /callout >}}

### Завершение прошивки

Снова дважды нажмите кнопку *Reset* с обратной стороны левой половинки и дождитесь, когда она перейдёт в режим загрузчика (откроется папка-хранилище)

Скопируйте или перетащите UF2-файл прошивки *K:04/mini/micro* для левой половинки, после чего она должна перезагрузиться
{{< callout type="info" >}}
  Если при копировании прошивки появляется окно с ошибкой копирования, просто игнорируйте это сообщение
{{< /callout >}}

{{< callout type="important" >}}
  Повторите те же шаги для **правой** половинки, но используйте UF2-файл прошивки *K:04/mini/micro* уже для **правой** половинки
{{< /callout >}}

{{% /steps %}}

Прошивка завершена, можно подключать клавиатуру к вашему устройству!

## Уход и обслуживание

- Периодически очищайте корпус от пыли и загрязнений сухой или влажной тканевой салфеткой
- **Для модуля трекбола:** следите за чистотой шара, керамических подшипников и полости установки шара

{{< callout type="info" >}}
  Для извлечения шара вытяните его в противоположную сторону относительно фиксатора на корпусе модуля
{{< /callout >}}

{{< callout type="error" >}}
  Не используйте агрессивные чистящие средства (ацетон, бензин, растворители (646, уайт-спирит), концентрированные кислоты и щелочи)!
{{< /callout >}}

{{< callout type="warning" >}}
  Не допускайте попадания жидкости внутрь устройства!
{{< /callout >}}
