{{< details title="LED indication — K:04 without Qube" closed="true" >}}

- **Layer color** — both halves show the color of the active layer 0–15. Colors, brightness, and the base-layer indication timeout are configured in [Entropy](https://github.com/ergohaven/entropy)
- **BT profile** — when switching between profiles BT0–BT4, both halves show the selected profile color for one second
- **Battery charge level** — when you press **BT Battery**, each half shows its own charge level for one second: 0–20% in red, 21–40% in orange, 41–74% in yellow, and 75–100% in green
- **Low battery** — if a half has 20% charge or less and is not connected via USB-C, it briefly blinks red every two seconds
- **Charging** — while connected via USB-C, a half lights up yellow on the base layer, then green at 95% charge or higher
- **BLE pairing** — both halves blink cyan: the keyboard is ready to pair
- **BLE reconnecting** — both halves blink white: the keyboard is trying to reconnect
- **Host connected** — after connecting to a computer via Bluetooth, both halves light up green for one second
- **Split missing** — a half blinks yellow while searching for the other half
- **Split connected** — after the halves connect, both light up green for one second
- **System off / deep sleep** — the LEDs turn off when the keyboard enters sleep mode unless the halves are connected via USB-C

{{< /details >}}

{{< details title="LED indication — K:04 with Qube" closed="true" >}}

- **Layer color** — both halves show the color of the active layer 0–15. Colors and brightness are configured in [Entropy](https://github.com/ergohaven/entropy)
- **Battery charge level** — the charge level of each half is continuously shown on the Qube display
- **Charging** — while connected via USB-C, a half lights up yellow on the base layer, then green at 95% charge or higher
- **Split missing** — a half blinks yellow while searching for Qube
- **Split connected** — after connecting to Qube, the half lights up green for one second
- **System off / deep sleep** — the LED turns off when the half enters sleep mode unless it is connected via USB-C

{{< /details >}}

## Connection

- **K:04** works with devices running Windows, macOS, Linux, Android, and iOS
- The keyboard connects via Plug and Play (PnP); no additional driver installation is required
- The keyboard ships ready to connect to your device with the firmware current at the time of purchase

{{% details title="Wired connection" closed="true" %}}

The keyboard supports wired connection via USB-C. Use the included cable or any other USB-C cable that supports data transfer
{{< callout type="info" >}}
  The **left half** of K:04 is the **master** and is intended for wired connection
{{< /callout >}}
{{% /details %}}

{{% details title="Wireless connection" closed="true" %}}
1. **Turn on both halves of the keyboard** — the halves are already synchronized with each other
2. **Select a connection profile on the keyboard** — if you need to connect to multiple devices, you can skip this step for the first connection
3. **Connect the keyboard to your device** — enable Bluetooth on the device, then pair it in the device settings
{{% /details %}}

{{% details title="Connecting additional devices" closed="true" %}}

1. Enable Bluetooth on the device you want to connect the keyboard to
2. Turn on the keyboard by switching the power switches on the bottom covers of both halves to the *ON* position — the keyboard will enter pairing mode
3. Switch the BT profile on the keyboard using the corresponding keys (layer 3 in the default layout)
3. Start a Bluetooth search on your device and find the keyboard in the list
4. Connect the keyboard to your device
{{% /details %}}

## Charging, Charge Monitoring

- use the included USB-C cable or any other USB-C cable to charge the keyboard
- a full battery charge takes about 1.5-2 hours
- without Qube, check the charge level of each half using LED indication (the **BT Battery** key); with Qube, check it on the Qube display

{{< callout type="warning" >}}
  To charge a keyboard half's battery, the power switch on the bottom of that half must be in the **ON** position
{{< /callout >}}

### Modular System Connection Notes
- after replacing one module with another, select it in [Entropy](https://github.com/ergohaven/entropy) under **Config** - **Modules settings**
- modules can be installed into the sockets on either half without reflashing
- when replacing one module with another, the configuration is preserved
- identical modules can be used on both halves
- if no module is installed, the socket is covered with a neat plug
- each module is configured separately for each half

## Configuration

Use the [Entropy](https://github.com/ergohaven/entropy) graphical configurator to remap keys and configure the keyboard

## Firmware Update

Firmware update is required when:
- A firmware update has been released on [keymap_hub](https://github.com/ergohaven/keymap_hub)
- You need to restore the keyboard to factory settings

{{% steps %}}

### Preparing for Firmware Update

Download the latest *Reset all settings for RMK* and *K:04/mini/micro* firmware files for the left and right halves from [keymap_hub](https://github.com/ergohaven/keymap_hub)

### Settings Reset Firmware

Connect the firmware device (PC, laptop, etc.) to the left half of the keyboard using a USB-C cable, then double-press the *Reset* button on the back of the keyboard

{{< callout type="info" >}}
  The keyboard will enter bootloader mode and a storage folder will open (if auto-run for connected drives is disabled on your device, navigate to the storage folder manually)
{{< /callout >}}

Copy or drag the *Reset all settings for RMK* UF2 file — the keyboard should reboot automatically

{{< callout type="info" >}}
  The Reset all settings for RMK firmware is used to wipe the keyboard's internal memory. It resets connection profile settings and half-synchronization settings
{{< /callout >}}

{{< callout type="important" >}}
  Repeat the same steps for the right half
{{< /callout >}}

### Completing the Firmware Update

Double-press the *Reset* button on the back of the left half again and wait for it to enter bootloader mode (the storage folder will open)

Copy or drag the *K:04/mini/micro* UF2 firmware file for the left half — it should reboot automatically
{{< callout type="info" >}}
  If a copy error dialog appears during firmware upload, simply ignore this message
{{< /callout >}}

{{< callout type="important" >}}
  Repeat the same steps for the **right** half, but use the *K:04/mini/micro* UF2 firmware file for the **right** half
{{< /callout >}}

{{% /steps %}}

Firmware update is complete — you can now connect the keyboard to your device!

## Care and Maintenance

- Periodically clean the case from dust and dirt using a dry or slightly damp cloth
- **For the trackball module:** keep the ball, ceramic bearings, and ball socket clean

{{< callout type="info" >}}
  To remove the ball, pull it out in the direction opposite the retaining tab on the module case
{{< /callout >}}

{{< callout type="error" >}}
  Do not use aggressive cleaning agents (acetone, gasoline, solvents (646, white spirit), concentrated acids or alkalis)!
{{< /callout >}}

{{< callout type="warning" >}}
  Do not allow liquid to get inside the device!
{{< /callout >}}
