## Package contents

{{< details title="USB-C cable" closed="true" >}}

The package includes one 2-meter USB-C to USB-A cable

{{< /details >}}

{{< details title="Switch puller" closed="true" >}}

If the keyboard is ordered with switches, a standard switch puller is included

{{< /details >}}

{{< details title="Additional switch plate" closed="true" >}}

K:04 Series keyboards come with a switch plate for low-profile Gateron Brown/Red KS-33 LP 3.0 switches installed by default

![K:04 — low-profile switches](/images/k04_series/k04_lp_switches.jpg)

If you use mid-profile MX switches, install the additional switch plate included in the package

{{< callout type="info" >}}
Install the additional switch plate with the matte smooth surface facing up
{{< /callout >}}

![K:04 — mid-profile switches](/images/k04_series/k04_middle_switches.jpg)

{{< /details >}}
