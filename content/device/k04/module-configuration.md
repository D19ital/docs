## Установка и замена

- Модули устанавливаются в разъёмы на любой половинке без перепрошивки
- Одинаковые модули можно использовать на обеих половинках
- Каждый модуль настраивается отдельно для каждой половинки
- При замене одного модуля на другой конфигурация сохраняется
- Если модуль не установлен, закройте разъём заглушкой

После установки или замены модуля выберите его тип в Entropy

## Выбор модуля в Entropy

1. Подключите клавиатуру к компьютеру по USB
2. Откройте [Entropy](/software/entropy/)
3. Перейдите в **Настройки → Настройки модулей**
4. В поле **Сторона модуля** выберите нужную половинку
5. В поле **Модуль** выберите установленный энкодер, тачпад или трекбол

![K:04 — настройка модулей](/images/k04_series/k04_modules_settings_ru.gif)

{{< callout type="info" >}}
Если модули не используются, отключите их в Entropy, чтобы увеличить время автономной работы клавиатуры
{{< /callout >}}

Общие сведения о переназначении клавиш находятся на странице [Настройка устройств в Entropy](/device/guides/configuration/)
