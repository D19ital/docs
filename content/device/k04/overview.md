## Комплектация

{{< details title="Кабель USB-C" closed="true" >}}

В комплект входит один кабель USB-C — USB-A длиной 2 метра

{{< /details >}}

{{< details title="Свитч-пуллер" closed="true" >}}

Если клавиатура заказана со свитчами, в комплект входит стандартный пуллер для их извлечения

{{< /details >}}

{{< details title="Дополнительный свитчплейт" closed="true" >}}

В клавиатурах серии K:04 по умолчанию установлен свитчплейт под низкопрофильные свитчи Gateron Brown/Red KS-33 LP 3.0

![K:04 — низкопрофильные свитчи](/images/k04_series/k04_lp_switches.jpg)

Если вы пользуетесь среднепрофильными MX-свитчами, установите дополнительный свитчплейт из комплекта

{{< callout type="info" >}}
Устанавливайте дополнительный свитчплейт матовой гладкой поверхностью вверх
{{< /callout >}}

![K:04 — среднепрофильные свитчи](/images/k04_series/k04_middle_switches.jpg)

{{< /details >}}
