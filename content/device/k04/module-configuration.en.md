## Installation and replacement

- Modules can be installed in the socket on either half without reflashing
- Identical modules can be used on both halves
- Each module is configured separately for each half
- Configuration is preserved when one module is replaced with another
- If no module is installed, cover the socket with the plug

Select the module type in Entropy after installing or replacing a module

## Selecting a module in Entropy

1. Connect the keyboard to the computer via USB
2. Open [Entropy](/software/entropy/)
3. Go to **Config → Modules settings**
4. Select the required half under **Module side**
5. Select the installed encoder, touchpad, or trackball under **Module**

![K:04 — module configuration](/images/k04_series/k04_modules_settings_en.gif)

{{< callout type="info" >}}
If you do not use modules, disable them in Entropy to increase keyboard battery life
{{< /callout >}}
