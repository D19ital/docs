Entropy показывает только те функции, которые поддерживает подключённое устройство

Если пункта нет в меню, это обычно означает, что прошивка не предоставила соответствующую возможность

## Настройки приложения

Откройте **Настройки → Настройки приложения**

| Параметр | Назначение |
| --- | --- |
| **Язык** | Переключает русский и английский интерфейс |
| **Легенды клавиш** | Показывает EN или EN/RU с выбранным порядком |
| **Работать в фоне** | Оставляет Live-интеграции и Text Expander активными после закрытия окна |
| **Запускать при входе** | Запускает Entropy вместе с пользовательской сессией |
| **Запускать свёрнутой** | Скрывает окно при автоматическом запуске |
| **Символы Shift на цифрах** | Показывает дополнительные символы над цифровым рядом |
| **Предпросмотр слоя** | Показывает целевой слой при наведении на layer-клавишу |
| **Увеличение энкодера** | Увеличивает энкодеры при наведении |
| **Акцентный цвет** | Меняет цвет активных элементов интерфейса |
| **Диагностика** | Записывает логи для поиска ошибок |
| **Интерактивный тур** | Повторно запускает обучение интерфейсу |

{{< layout-lightbox src="/images/entropy/settings-app.png" alt="Настройки приложения Entropy" width="900" >}}

Кнопки **Импорт настроек** и **Экспорт настроек** работают с файлами `.entsettings` и позволяют перенести параметры приложения и правила Text Expander

В Linux на этой странице также доступна установка правил udev для Vial

## Макросы

Макрос выполняет последовательность действий после нажатия одной клавиши

1. Нажмите клавишу на раскладке
2. Откройте вкладку **Макросы**
3. Выберите слот макроса
4. Укажите имя и необязательное описание
5. Добавьте действия в нужном порядке
6. Назначьте слот выбранной клавише

{{< video autoplay="true" loop="true" muted="true" src="/video/entropy/macros.mp4" >}}

Доступные действия:

- **Text** — ввод текста по символам
- **Tap** — нажатие и отпускание клавиши
- **Down** — удержание клавиши до действия `Up`
- **Up** — отпускание ранее удерживаемой клавиши
- **Delay** — пауза в миллисекундах

Имена и описания сохраняются локально и включаются в `.entlayout`

## Tap Dance

Tap Dance назначает разные действия одной клавише в зависимости от способа нажатия

- **Tap** — короткое нажатие
- **Hold** — удержание
- **Double Tap** — двойное нажатие
- **Tap + Hold** — нажатие, затем удержание

Параметр **Окно tap/hold** задаёт время, за которое прошивка различает эти действия

## Combo

Combo отправляет одно действие при одновременном нажатии двух–четырёх входных клавиш

Откройте **Дополнительно → Combo**, выберите слот, укажите входные клавиши и выходное действие

Таймаут Combo определяет максимально допустимый интервал между входными нажатиями

{{< video autoplay="true" loop="true" muted="true" src="/video/entropy/combo.mp4" >}}

## Key Overrides

Key Override заменяет клавишу при выполнении условий модификаторов и слоя

- **Триггер** — исходная клавиша
- **Замена** — отправляемое действие
- **Триггер-модификаторы** — обязательные модификаторы
- **Блокирующие модификаторы** — условия, при которых правило не работает
- **Подавляемые модификаторы** — модификаторы, скрываемые во время замены
- **Активно на слоях** — слои, на которых правило разрешено

## Text Expander

Text Expander заменяет короткие локальные триггеры готовым текстом и работает на компьютере, а не в прошивке устройства

{{< layout-lightbox src="/images/entropy/text-expander.png" alt="Text Expander" width="900" >}}

### Создание правила

1. Откройте **Дополнительно → Экспандер текста**
2. Включите экспандер
3. Добавьте правило
4. Введите триггер, например `:mail`
5. Введите текст замены

{{< video autoplay="true" loop="true" muted="true" src="/video/entropy/text-expander.mp4" >}}

Триггер должен начинаться с `:` или `;` и не должен содержать пробелы

В тексте замены используйте `\n` для новой строки и `$|$` для позиции курсора после вставки

Дополнительные возможности:

- Blacklist приложений, в которых замена отключена
- Подключение нескольких JSON-файлов с правилами
- Автоматическое перечитывание изменённых файлов
- Многострочные шаблоны

### Поддержка ОС

- Windows использует нативный бэкенд Entropy
- macOS требует Accessibility и Input Monitoring
- Linux использует источник ввода Entropy IBus

Entropy должна оставаться запущенной в фоне, а на Linux должен быть выбран источник ввода Entropy Text Expander

## Тренажёр печати

Откройте **Дополнительно → Тренажёр печати**, чтобы провести локальный тест скорости

- Режим по времени: 15, 30, 60 или 120 секунд
- Режим по количеству: 10, 25, 50 или 100 слов
- Английские и русские наборы слов
- Дополнительная пунктуация и цифры
- WPM, точность, ошибки и локальная история результатов

## Matrix Tester

Matrix Tester показывает нажатия физических свитчей и помогает найти несрабатывающую позицию

{{< layout-lightbox src="/images/entropy/matrix-tester.png" alt="Matrix Tester" width="900" >}}

Откройте **Настройки → Тестер матрицы**, нажмите несколько клавиш и следите за счётчиком проверенных позиций

Тестер работает только с совместимыми Vial-устройствами и может потребовать разблокировки

## Layout Indicator

Layout Indicator — отдельное окно с текущим слоем и состоянием клавиш

Откройте **Раскладка → Индикатор раскладки**

- Закрепляйте окно поверх других приложений
- Меняйте прозрачность
- Показывайте полную раскладку или только нажатия
- Отслеживайте активный слой, Combo и Tap Dance

{{< video autoplay="true" loop="true" muted="true" src="/video/entropy/matrix-indicator.mp4" >}}

## Live-интеграции

Откройте **Настройки → Live-интеграции**, чтобы проверить доступные данные, которые Entropy передаёт прошивке

- **Синхронизация времени** — локальные часы компьютера
- **Синхронизация громкости** — громкость основного устройства вывода
- **Медиа-информация** — исполнитель и название активного трека
- **Синхронизация раскладки** — текущая раскладка EN/RU

Для Live-интеграций Entropy должна работать в фоне

Подробнее о синхронизации раскладки см. в разделе [Универсальные символы](../universal-symbols)
