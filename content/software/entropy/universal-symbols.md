Универсальные символы позволяют назначить пунктуацию, которая вводится одинаково в английской и русской раскладках ОС

Обычная клавиша отправляет один и тот же HID-код, поэтому результат зависит от активной раскладки, а универсальное действие выбирает правильную комбинацию на стороне совместимой RMK-прошивки

{{< callout type="important" >}}
Универсальные символы работают только на Vial-RMK устройствах, прошивка которых сообщает Entropy о поддержке этой функции
{{< /callout >}}

После назначения символы работают автономно в прошивке и не требуют постоянно запущенной Entropy

Entropy нужна для настройки и автоматической синхронизации текущей раскладки ОС

## Доступные символы

Вкладка **Универсальные** содержит 32 знака ASCII-пунктуации:

```text
. , ; : ! ? / ` ~ ' " ( ) [ ] { } < >
- + * = # @ $ % ^ & | \ _
```

{{< video autoplay="true" loop="true" muted="true" src="/video/entropy/universal-picker.mp4" >}}

Совместимая прошивка также предоставляет русские буквы `х`, `б`, `ю` и `ъ` в разделе **Спец → Международные**, удержание Shift вводит заглавную букву

Unicode-типографика, стрелки, математические знаки и дополнительные валютные символы в этой версии не поддерживаются

## Назначение

1. Подключите совместимое RMK-устройство
2. Откройте нужный слой
3. Нажмите клавишу на раскладке
4. Перейдите на вкладку **Универсальные**
5. Выберите знак пунктуации или управляющее действие

В Entropy такие назначения отображаются двухстрочной легендой `Universal` и выбранным символом или названием действия

## Управляющие действия

| Действие | Что делает | Когда использовать |
| --- | --- | --- |
| `Toggle` | Переключает раскладку English/Russian и состояние прошивки | Основная ручная клавиша смены языка |
| `Sync` | Переключает только внутреннее состояние раскладки в прошивке, не меняя раскладку ОС | Когда ОС и прошивка оказались в разных состояниях |
| `EN` | Явно переключает раскладку и состояние прошивки на English | Для отдельной клавиши перехода на английский |
| `RU` | Явно переключает раскладку и состояние прошивки на Russian | Для отдельной клавиши перехода на русский |
| `macOS` | Переключает соответствия русской раскладки между PC и macOS | Для корректной пунктуации на macOS |

`Toggle`, `EN` и `RU` подходят для автономной работы без Entropy

`Sync` не отправляет системное переключение языка, поэтому исправляет состояние прошивки, не меняя уже выбранную раскладку ОС

Действие `macOS` меняет таблицу соответствий в прошивке: оставьте режим PC для Windows/Linux и включите macOS на компьютерах Apple

{{< video autoplay="true" loop="true" muted="true" src="/video/entropy/universal-controls.mp4" >}}

В Layout Indicator активная клавиша подсвечивается, а системный индикатор языка позволяет проверить результат `Toggle`, `EN` и `RU`

## Layout Sync

Layout Sync передаёт прошивке текущую раскладку ОС и автоматически исправляет её внутреннее состояние после системного переключения языка

1. Откройте **Настройки → Live-интеграции**
2. Найдите строку **Синхронизация раскладки**
3. Убедитесь, что отображается состояние **готово**
4. Включите переключатель
5. Разрешите Entropy работать в фоне

{{< layout-lightbox src="/images/entropy/layout-sync.png" alt="Layout Sync готов к работе" width="900" >}}

{{< video autoplay="true" loop="true" muted="true" src="/video/entropy/layout-sync.mp4" >}}

Когда Layout Sync включён, язык можно менять средствами операционной системы, а Entropy синхронизирует состояние прошивки

| Система | Источник данных |
| --- | --- |
| Windows | Раскладка активного окна |
| KDE Plasma | Активная раскладка через D-Bus на Wayland или X11 |
| GNOME | Активная раскладка через IBus D-Bus на Wayland или X11 |
| Другие окружения Linux X11 | Активная группа XKB |
| macOS | Текущий источник ввода |

В других Wayland-окружениях Linux строка может показывать **нужна настройка**, в этом случае используйте управляющие действия прошивки или совместимую сессию KDE/GNOME/X11

{{< callout type="info" >}}
IBus нужен Universal Symbols только как источник состояния раскладки в GNOME, сами символы вводит прошивка. Отдельный бэкенд Entropy IBus устанавливается только для Text Expander
{{< /callout >}}

## Какой режим выбрать

### Entropy постоянно работает в фоне

Включите Layout Sync и переключайте язык привычными средствами ОС

Оставьте `Sync` на доступном слое как средство ручного исправления рассинхронизации

### Entropy не работает в фоне

Назначьте `Toggle` либо отдельные `EN` и `RU`, чтобы прошивка самостоятельно управляла языком

Если язык был изменён другим способом и символы стали неправильными, нажмите `Sync` один раз и проверьте ввод

## Проверка

1. Откройте текстовый редактор
2. Выберите английскую раскладку
3. Нажмите назначенный универсальный символ
4. Переключитесь на русскую раскладку
5. Нажмите ту же клавишу

В обоих случаях должен появиться одинаковый знак

Если символ отличается, проверьте Layout Sync, нажмите `Sync` и убедитесь, что выбран правильный режим PC/macOS

## Если вкладки нет

- Обновите RMK-прошивку устройства до версии с Universal Symbols
- Переподключите устройство
- Откройте **Раскладка → Об устройстве → Обновить данные устройства**, если прошивка была обновлена без смены имени
- Убедитесь, что устройство подключено через Vial-RMK, а не через прошивку без этой возможности
