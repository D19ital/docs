## Entropy не запускается

{{< tabs items="Windows,macOS,Linux" >}}
  {{< tab >}}

- Убедитесь, что скачана сборка `windows-x86_64.exe`
- В окне SmartScreen нажмите **Подробнее → Выполнить в любом случае**
- Переместите файл из временной папки в постоянную и запустите снова
- Проверьте, не заблокировал ли файл антивирус

  {{< /tab >}}
  {{< tab >}}

- Убедитесь, что выбрана правильная архитектура: `arm64` для Apple Silicon или `x86_64` для Intel
- Перетащите приложение из DMG в `/Applications`
- Выполните:

  ```bash
  xattr -dr com.apple.quarantine /Applications/Entropy.app
  open /Applications/Entropy.app
  ```

  {{< /tab >}}
  {{< tab >}}

- Разрешите запуск AppImage командой `chmod +x <файл>.AppImage`
- Запускайте файл из локальной файловой системы, а не напрямую из архива или сетевой папки
- Если окно не открывается, запустите AppImage из Terminal и сохраните текст ошибки

## Устройство не найдено

1. Проверьте USB-кабель или заряд устройства
2. Переподключите устройство и подождите повторного сканирования
3. Откройте меню **Раскладка** и выберите устройство вручную
4. Закройте другие конфигураторы, которые могут удерживать HID-интерфейс
5. Проверьте устройство на другом USB-порту

Для Bluetooth сначала выполните сопряжение в настройках ОС, затем выберите Bluetooth-подключение в Entropy

Если в списке есть USB и Bluetooth одного устройства, выберите транспорт, который используется сейчас

### Linux

Откройте **Настройки → Настройки приложения → Доступ к Vial**, нажмите **Установить rules** и переподключите устройство

Не запускайте Entropy от имени root для обычной работы

### macOS Bluetooth

Разрешите Entropy в **System Settings → Privacy & Security → Input Monitoring**, полностью закройте приложение и запустите снова

## Устройство заблокировано

Некоторые Vial-устройства запрещают изменение настроек до разблокировки

1. Откройте **Настройки**
2. Нажмите **Разблокировать устройство**
3. Удерживайте подсвеченные на раскладке физические клавиши
4. Дождитесь сообщения об успешной разблокировке

После изменения настроек устройство можно снова заблокировать через то же меню

## Данные загружаются слишком долго

При Bluetooth-подключении Entropy сначала загружает первый слой, а остальные слои и настройки читает в фоне

- Не переключайте устройство во время первоначальной загрузки
- Нажмите **Повторить**, если ошибка появилась только у одного раздела
- Переподключите устройство при повторяющейся ошибке
- Откройте **Раскладка → Об устройстве → Обновить данные устройства**, если прошивка недавно обновлялась

Обновление данных удаляет локальный кэш схемы устройства и считывает его заново

## Нужного пункта нет в меню

Entropy скрывает функции, которые не предоставлены прошивкой

- Проверьте версию прошивки
- Подключите устройство и дождитесь полной загрузки данных
- Обновите данные устройства после перепрошивки
- Убедитесь, что нужная возможность поддерживается именно этой прошивкой

Отсутствие RGB, Auto Shift, Combo, модулей, Universal Symbols или другой страницы не является ошибкой интерфейса, если прошивка не сообщает о её поддержке

## Изменения не сохраняются

- Разблокируйте Vial-устройство
- Дождитесь состояния **Сохранено** перед отключением
- Не выполняйте несколько длительных операций одновременно по Bluetooth
- При состоянии **Ошибка записи** переподключите устройство и повторите изменение
- Создайте резервную копию перед повторным импортом большой раскладки

## Ошибка импорта `.entlayout`

- Проверьте, что выбран файл `.entlayout`, а не обычный JSON другого формата
- Не изменяйте поля `format` и `version` вручную
- Подключите целевое устройство до начала импорта
- Используйте точное сопоставление для той же модели и универсальное сопоставление для совместимой другой геометрии
- Изучите разделы **Пропущено** и **Проблемы прошивки** в отчёте

Перед применением Entropy создаёт автоматическую резервную копию текущей раскладки

## Text Expander не срабатывает

### Общие проверки

- Включите **Экспандер текста**
- Убедитесь, что Entropy работает в фоне
- Проверьте, что триггер начинается с `:` или `;` и не содержит пробелов
- Убедитесь, что активное приложение не добавлено в blacklist
- Проверьте правило на простом однострочном тексте

### Windows

Перезапустите Entropy и проверьте правило в Notepad

### macOS

Выдайте Accessibility и Input Monitoring, затем нажмите **Перезапустить перехват** в настройке бэкенда

### Linux

Установите IBus, добавьте источник **Entropy Text Expander** и выберите его перед вводом триггера

## Универсальный символ вводится неправильно

1. Проверьте, что клавише назначено действие со вкладки **Универсальные**, а не обычный символ
2. Откройте **Настройки → Live-интеграции** и проверьте состояние Layout Sync
3. Нажмите `Sync` один раз
4. Проверьте режим `macOS`: он должен быть выключен на Windows/Linux и включён на macOS
5. Повторите тест в английской и русской раскладках

Подробнее см. в разделе [Универсальные символы](../universal-symbols)

## Сбор диагностических данных

1. Откройте **Настройки → Настройки приложения**
2. Включите **Диагностика**
3. Повторите ошибку
4. Отключите диагностику после завершения проверки

При обращении за помощью укажите:

- Версию Entropy из **Об Entropy**
- Операционную систему и окружение рабочего стола
- Модель устройства и версию прошивки из **Об устройстве**
- Тип подключения: USB или Bluetooth
- Последовательность действий до ошибки
- Текст сообщения об ошибке и диагностический лог

Перед отправкой удалите из логов имена пользователей, локальные пути и другие личные данные
