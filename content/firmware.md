Актуальные прошивки для устройств ввода Ergohaven.

{{< callout type="info" >}}
  Инструкцию по обновлению прошивки смотрите в документации к вашему устройству.
{{< /callout >}}

Выберите точную модель и ревизию устройства. После выбора появятся доступные файлы прошивки.

{{< firmware-picker >}}

{{< callout type="warning" >}}
  Файлы для левой и правой половин не взаимозаменяемы. Если показано несколько кнопок, скачайте все файлы, необходимые для вашего устройства.
{{< /callout >}}
